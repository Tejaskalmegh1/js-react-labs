## `01` / THE VISION

**More than a collection of code. A continuous engineering practice.**

`js-react-labs` is my personal development workspace for exploring JavaScript, mastering React, experimenting with implementation patterns, and building increasingly sophisticated applications.

Every implementation is an opportunity to understand the underlying concepts, improve problem-solving ability, and write more maintainable code.

**Core principles**

- ◈ **Understand deeply** — Focus on the reasoning behind every implementation.
- ◈ **Build practically** — Turn concepts into functional implementations.
- ◈ **Engineer thoughtfully** — Prioritize readability, modularity, and maintainability.
- ◈ **Iterate continuously** — Refine existing solutions as understanding improves.
- ◈ **Document intentionally** — Keep experiments understandable and reproducible.

## `07` / ENGINEERING STANDARDS

The goal is not simply to make code work, but to make it understandable, testable, and maintainable.

- Consistent naming and predictable file organization
- Small, focused functions and reusable components
- Clear separation of application logic and presentation
- Immutable state updates where appropriate
- Explicit handling of errors and edge cases
- Meaningful comments and implementation notes
- Appropriate tests for important behavior
- Focused commits with descriptive messages

**Commit style**

```text
feat: add reusable array utilities
feat: implement custom React hook
fix: handle failed API requests
refactor: simplify state update logic
test: cover task filtering behavior
docs: improve JavaScript concept notes
```

## `10` / GET STARTED

**Requirements:** Node.js LTS, Git, and a code editor.

Clone the repository:

```bash
git clone https://github.com/Tejaskalmmegh1/js-react-labs.git

cd js-react-labs
```

Run a JavaScript implementation:

```bash
node javascript/fundamentals/variables-and-types/variables.js
```

Run a React project:

```bash
cd projects/react-applications/<project-name>

npm install
npm run dev
```

Replace the example paths with the directories and files that exist in your repository.
